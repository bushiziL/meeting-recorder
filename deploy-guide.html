🚀 录音即纪要 — OSS 部署指南

将项目部署到阿里云 OSS 静态网站托管，绑定自定义域名 mvpskill.cn

📊 整体流程概览

① 创建 OSS Bucket

在阿里云控制台创建存储桶，开启静态网站托管

② 获取 AccessKey

创建 RAM 子账号并生成 AccessKey，用于部署脚本

③ 配置并部署

填写 .env.oss 配置文件，运行部署脚本上传文件

④ 绑定域名

OSS 绑定自定义域名 + 阿里云 DNS 配置解析

第一步：创建 OSS Bucket

1打开 OSS 控制台

访问 https://oss.console.aliyun.com/

点击左侧 Bucket 列表 → 右上角 创建 Bucket

2填写 Bucket 配置

配置项填写内容说明
Bucket 名称meeting-recorder全局唯一，如果已被占用可加后缀如 meeting-recorder-cn
地域华东1（杭州）选择离你用户最近的地域
存储类型标准存储—
读写权限公共读必须选公共读，否则网站无法访问
版本控制不开通—
⚠️ 读写权限必须选公共读，私有权限会导致网页无法加载！

3开启静态网站托管

Bucket 创建完成后：

  1. 进入 Bucket → 左侧菜单 数据管理 → 静态页面
  2. 打开 静态页面 开关
  3. 默认首页填：index.html
  4. 默认 404 页填：index.html 重要
  5. 点击保存
💡 404 页也填 index.html 是因为 SPA 应用需要所有未知路径都返回 index.html

第二步：获取 AccessKey

1创建 RAM 子用户（推荐，比用主账号更安全）

访问 https://ram.console.aliyun.com/users

  1. 点击 创建用户
  2. 登录名称：oss-deploy
  3. 勾选 OpenAPI 调用访问（即编程访问）
  4. 点击确定
  5. 重要 创建后立刻复制 AccessKey ID 和 AccessKey Secret，只显示一次！

2给子用户授权

在用户列表找到 oss-deploy → 点击 添加权限

权限策略说明
AliyunOSSFullAccessOSS 完全访问（上传/删除文件）
💡 如果只想限制到特定 Bucket，可以创建自定义策略，但为了简便先用系统策略

第三步：配置并部署

1创建配置文件

在项目根目录创建 .env.oss 文件：

OSS_REGION=oss-cn-hangzhou
OSS_BUCKET=meeting-recorder
OSS_AK=你的AccessKey_ID
OSS_SK=你的AccessKey_Secret
CUSTOM_DOMAIN=mvpskill.cn
💡 OSS_REGION 根据你创建 Bucket 时选的地域填写：
华东1(杭州) → oss-cn-hangzhou
华东2(上海) → oss-cn-shanghai
华北2(北京) → oss-cn-beijing
华南1(深圳) → oss-cn-shenzhen

2构建并部署

在项目目录运行：

# 1. 构建项目
npm run build

# 2. 部署到 OSS
node deploy-oss.cjs

看到 🎉 部署成功！ 即表示上传完成。

3验证部署

在浏览器打开 OSS 默认域名测试：

https://meeting-recorder.oss-website-cn-hangzhou.aliyuncs.com

替换为你的 Bucket 名和地域。如果看到落地页，说明部署成功！

第四步：绑定自定义域名

1OSS 绑定域名

在 OSS 控制台：

  1. 进入 Bucket → 左侧 域名管理
  2. 点击 绑定域名
  3. 输入：mvpskill.cn
  4. 同时再绑定：www.mvpskill.cn

2配置阿里云 DNS 解析

访问 https://dc.console.aliyun.com/dns

找到 mvpskill.cn → 点击 解析设置 → 添加以下记录：

记录类型主机记录记录值说明
CNAMEwwwmeeting-recorder.oss-website-cn-hangzhou.aliyuncs.comwww 子域指向 OSS
CNAME@meeting-recorder.oss-website-cn-hangzhou.aliyuncs.com主域名指向 OSS
💡 cn-hangzhou 部分替换为你实际选择的地域代码

3开启 HTTPS（免费证书）

在 OSS 控制台：

  1. 进入 Bucket → 域名管理
  2. 找到绑定的域名，点击 证书托管
  3. 选择 免费证书（阿里云提供免费的 DV 证书）
  4. 提交后等待审核（通常几分钟内完成）
✅ 完成后访问 https://mvpskill.cn 即可看到你的网站！

后续更新部署

以后每次修改代码后，只需要两步：

npm run build
node deploy-oss.cjs

脚本会自动覆盖更新所有文件。

❓ 常见问题

Q: 访问 mvpskill.cn 显示 404？

检查 Bucket 的静态页面设置，确认默认首页和 404 页都填了 index.html。

Q: /app/ 页面白屏？

确认 404 页设为 index.html。SPA 路由需要服务端将所有未匹配路径都返回 index.html。

Q: 部署脚本报 "Access denied"？

检查 AccessKey 是否正确，RAM 用户是否已授权 AliyunOSSFullAccess。

Q: HTTPS 证书申请失败？

确认 DNS 解析已生效（可能需要等待几分钟），然后再申请证书。可以用 nslookup mvpskill.cn 验证解析是否指向 OSS。

Q: 需要开通 CDN 加速吗？

如果用户遍布全国，建议开通阿里云 CDN。在 OSS Bucket → 传输管理 → 域名与通信管理 中可以一键开启 CDN 加速。对于初期项目，OSS 自带带宽通常够用。
